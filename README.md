# 🎨✨ Tiago Montenegro 🚀🌌

A tiny 🎭 single-page web experience with a dramatic 🖼️ centerpiece image, a smooth ✨ motion loop, and a fun 🧠 interactive effect that rains tiny image particles when you press the ⌨️ AltGr key.

This project is a lightweight 🌐 static HTML/CSS/JavaScript page that turns a still image into a playful 🎉 animated visual experience.

## 🌟 Overview

The repository contains a minimalistic 🖤 dark-themed landing page that:

- centers a large 🖼️ image on the screen
- adds a gentle 🔄 looping motion effect
- creates a magical 🌧️ particle rain using image fragments
- responds to keyboard input 🎮 to trigger the animation
- respects ♿ reduced-motion preferences

## 📁 Project Structure

- `index.html` — 🧩 the full page structure, styling, and interactive JavaScript
- `IMG_2847.JPG` — 🖼️ the main hero image
- `tmcds1.png` — 🌠 one of the falling image assets
- `tmcds2.png` — 🌠 second falling image asset

## ✨ Features

- 📱 responsive full-screen layout
- 🔁 CSS animation for subtle movement
- ⌨️ keyboard-triggered particle rain effect
- 🧑‍🦽 accessibility support with reduced-motion handling
- ⚙️ no dependencies, no install step, no build toolchain needed

## ▶️ Run Locally

Because this is a static 🌐 site, you can run it in a few easy ways:

### Option 1: Open directly 🚀

Open `index.html` in your browser.

### Option 2: Use a local web server 🖥️

From the repository root, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## ⌨️ Keyboard Interaction

Press and hold the Right Alt / AltGr key 🕹️ to trigger the falling image animation. Release it to stop the effect 🌧️✨

This project is intentionally lightweight 🪶 and self-contained. It does not rely on any external libraries 📚 or frameworks 🏗️.
